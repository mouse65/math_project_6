
# Кластеризация изображений транспортных средств

## 🎯 Цель проекта
Провести кластеризацию изображений автомобилей на основе различных дескрипторов и алгоритмов   машинного обучения,
выявить  скрытую структуру данных, определить выбросы и интерпретировать полученные кластеры.  

Проект демонстрирует навыки работы с изображениями, извлечением признаков, кластеризацией и оценкой качества моделей.

## 🧠 Использованные методы

- Алгоритмы кластеризации:
  - **KMeans**
  - **Birch**
  - **AgglomerativeClustering**
  - **DBSCAN** (для поиска выбросов)

- Метрики оценки качества:
  - **Calinski-Harabasz Index**
  - **Davies-Bouldin Index**

- Предобработка данных:
  - **StandardScaler**
  - **MinMaxScale**
  - **RobustSkaler**
  - **PCA** (для снижения размерности)

## 📊 Дескрипторы изображений

- **efficientnet-b7** — универсальный нейросетевой эмбеддинг
- **osnet** — дескриптор для идентификации объектов
- **vdc_color** — цветовые характеристики
- **vdc_type** — тип кузова
  
Позволяют сравнить, как разные представления изображения влияют на качество кластеризации.
## 📈 Результаты

- Лучшие метрики кластеризации получены при использовании **osnet + KMeans**.
- **DBSCAN** корректно выделил выбросы — изображения с нестандартными цветами, ракурсами или формами.
- Построены графики зависимости метрик от числа кластеров и алгоритмов.
- Результаты кластеризации сохранены в CSV (path, cluster), что позволяет использовать их в дальнейших задачах.
